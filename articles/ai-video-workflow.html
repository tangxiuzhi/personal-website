摘要

作者 Eian 分享一套尽量少花钱、降低“抽卡率”的 AI 视频工作流。工具层以 Claude Code 做总导演，Codex 负责出图，Seedance 生成视频，并用 ffmpeg 与 Python 做后期；原则是错误尽量先在文字和图上发现，不要留到按秒计费的视频生成。操作上从完善剧情开始，强调现实逻辑、一句话主题和开头抓人，并避开人物交叉、小物件、镜子等模型易错画面；随后用参考片或详细分镜确定机位、运动和配色，再画设定图与每个镜头的首尾帧，用七段式提示词写清每秒动作，提交前另开 Agent 核对细节。生成时建议先用 720p，必要时再放大；出问题先剪掉或用代码修补，不要立刻重拍。成片后再用独立审核 Agent 通看一遍，并把经验沉淀下来。文中完整提示词和分工表多以配图给出，本次摘要依据已提取的文字部分。
