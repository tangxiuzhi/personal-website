摘要

作者实践哥 Li 在这篇文章里介绍了开源项目 BiliPicks：一个没有推荐算法的学习站点，用来给孩子看精选的科学、数学和 AI 内容。灵感来自 Andrej Karpathy 用 Claude Code 快速做一个无推荐流的 YouTube 入口。作者使用蚂蚁百灵 Ling-3.2-flash 和编程工具 pi，从空目录做起，嵌入 B 站官方播放器，把学习做成可打卡、解锁徽章的主线任务，路线从科学实验、动手制作逐步过渡到数学、编程和机器学习。首批约 20 条视频，来源包括中国科学技术馆、李永乐、3Blue1Brown、毕导、科普中国、StatQuest、Karpathy、李飞飞等。作者认为同一思路也可用于成人：自己选择信源，让 Agent 筛选整理，而不是跟着平台推荐走。代码与提示词已经开源，并提供在线体验。
