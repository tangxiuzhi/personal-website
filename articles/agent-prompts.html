作者数字生命卡兹克整理了近两个月用 Agent 做事时最常用的十条提示词，重点不在套话，而在改变模型与自己的思考方式。其中包括：从第一性原理找本质原因再修复；先问清模糊之处并给出多版方案；不要默认用户对问题的定义是对的，先判断是否把症状当成原因、把手段当成目标；评估改动的二阶、三阶影响，包括维护成本；用跨领域类比寻找更优解；先假设当前方案是错的，从最强反对者角度寻找反例；结合 Git 历史和关键 PR 区分有意设计与历史包袱；以“明天要交给一位不熟悉项目但能力很强的工程师”为标准评估认知成本；以及复盘最慢的 PR 和反复出现的问题，把共因沉淀成规则、自动化或 Skill。这是一份可公开阅读的工作方法笔记，不是逐步操作教程。
