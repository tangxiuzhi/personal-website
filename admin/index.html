管理员登录

使用有本仓库写入权限的 GitHub 账号授权，直接发布到网站。

  1. 在 GitHub 创建 Fine-grained personal access token。
  2. 仅选择 personal-website 仓库，将 Contents 设为 Read and write。
  3. 粘贴下方授权凭证，连接管理后台。
前往 GitHub 创建授权凭证

凭证只用于当前页面，刷新或退出后需重新连接。请仅在自己的设备上使用。

内容保存后，网站将在 GitHub Pages 部署完成后更新。
